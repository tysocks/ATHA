# ROCKETS System Analysis
## Source: 19910011919.pdf — Large Liquid Rocket Engine Transient Performance Simulation System
## NASA/Pratt & Whitney, Final Report, November 1991

---

## Overview

ROCKETS (Rocket Engine Transient Simulation) is a modular FORTRAN-based framework
for cost-effective prediction of liquid rocket engine transient performance.
Developed by P&W for NASA-MSFC. ~100,000 lines of executable code.

Key innovation: component modules stored in a library, connected in any topology
via a Configuration Processor that generates a FORTRAN main program automatically.

---

## System Architecture (Five Components)

1. **Library System** — central code repository for multi-user access
2. **Executive Programs (Processors)** — Configuration Processor, Run Processor, Execution Processor, Output Processor
3. **Simulation I/O** — user inputs and output parameters
4. **Documentation** — SDS, Engineering Manual, User's Manual, Programmer's Manual
5. **Maintenance Procedures**

---

## Three Run Modes

### 1. Steady-State Trim Balance
- Drives all dX/dt to zero
- Closes all algebraic loops simultaneously
- Modified Newton-Raphson iteration
- Supports multiple consecutive operating points (throttle sweeps)

### 2. Transient
- Predictor-corrector integration
- Corrector equations closed by modified Newton-Raphson at each step
- Dynamic states: volume dynamics, flow inertia, thermal capacitance
- Algebraic balances enforced simultaneously with integration
- States can be individually activated/deactivated or forced to steady-state
  (useful for reduced-order model generation)

### 3. Linearization
- Perturbs each state and specified input
- Produces A, B, C, D state-space matrices
- Xdot = A*X + B*U, Y = C*X + D*U
- Double precision matrix inversion (Gauss-Jordan + recursion)
- Repeatability and linearity checking built in

## Integration Methods

| Method | Form | Notes |
|--------|------|-------|
| Euler | Integral | Simplest, least stable |
| Trapezoidal | Integral + Differential | Stable for moderate stiffness |
| First-order Gear | Integral + Differential | Better for stiff systems |
| Second-order Gear | Integral + Differential | Best for stiff systems |

**Key insight:** ROCKETS automatically selects integral vs. differential corrector
form based on ratio of time step to state time constant. Each module approximates
its own time constant and flags which form to use. This is analogous to modern
adaptive stiffness detection in SciPy's LSODA.

## Newton-Raphson Solver Details

- Multi-variable Newton-Raphson: ΔX = J⁻¹ ΔY
- Jacobian generated by (n_vars + 1) passes through model
- Jacobian scaling via modified McLaughlin method (improves condition number)
- Broyden's method for inverse Jacobian updates between full evaluations
  (secant-type, avoids expensive re-inversion at each step)
- Convergence checked with scaled residuals

## State Variable Choice: P and h (NOT density and internal energy)

**Critical design decision.** Using density and internal energy as integration
states causes numerical problems in liquid systems:
- Extreme sensitivity of pressure to density (stiff)
- Difficult to provide first guesses for internal energy

**Solution:** Iterate on pressure and enthalpy instead.
- P and h are the natural thermodynamic potentials for flow networks
- CoolProp's primary hot path is state_from_Ph() for exactly this reason
- Conservation equations rewritten in (P, h) form

## Dynamic State Categories

### Volume Dynamics (states: P, h)
Conservation of mass + energy in a lumped volume:
```
dP/dt = (γ_eff * R_eff * T / V) * Σ(ṁ_in - ṁ_out) + enthalpy_correction
dh/dt = (1/m) * (Q̇_net + Σ(ṁ_in*h_in) - Σ(ṁ_out*h_out) - V*dP/dt)
```

### Flow Inertia Dynamics (state: ṁ)
Conservation of momentum in a pipe:
```
dṁ/dt = (A/L) * (P_in - P_out - ΔP_friction)
```
Used for long feed lines where acoustic delay matters.

### Thermal Capacitance (state: T_wall)
Lumped wall thermal mass:
```
dT_wall/dt = (Q̇_hot - Q̇_cool) / (m_wall * Cp_wall)
```

## TTBE Validation Case

Technology Test Bed Engine (TTBE) — SSME derivative, LOX/LH2 staged combustion.

**Simple TTBE Model:** 55 states, 2 algebraic loops
**Detailed TTBE Model:** 122 states, 14 algebraic balances
- Fuel side + oxidizer side + hot gas system
- Validated against Rocketdyne Digital Transient Model (DTM)
- 10ms time step (50x larger than DTM) with implicit integration
- Agreement typically within 3% for most parameters

**Key steady-state parameters used for validation:**
- Main chamber pressure vs. RPL (Rated Power Level)
- Turbine speeds vs. RPL
- Flow rates, pressures, rotor speeds during throttle transients
